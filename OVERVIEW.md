# HackMates - Platform Overview

HackMates is India's premier hackathon community platform that connects developers, designers, and innovators through AI-powered matching, reliability tracking, and smart team formation. Built with React, TypeScript, and Firebase, it provides a comprehensive ecosystem for discovering hackathons, finding compatible teammates, and building winning projects with confidence.

## Core Features

- **AI-Powered Assistant** - Gemini AI mentor providing personalized hackathon guidance, project ideas, technical support, and pitch coaching
- **Reliability & Trust System** - 4-tier badge system (Newbie → Reliable → Finisher → Legend) with team feedback and trust scores
- **Synergy Matching Algorithm** - Smart compatibility scoring based on work style, goals, schedule, and commitment levels
- **Hackathon Discovery & Management** - Browse, create, and manage hackathons with smart filtering and team formation
- **Intelligent Profile Recommendations** - AI-powered teammate suggestions with skill matching and synergy analysis
- **Real-time Communication** - Direct messaging, hackathon group chats, and instant notifications
- **Smart Announcements** - Event updates with unread tracking and real-time delivery
- **Comprehensive Profiles** - Showcase skills, experience, work style preferences, and achievements
- **Team Feedback System** - Post-hackathon ratings to build community trust and reputation
- **Work Style Preferences** - Match based on goals (win vs learn), time preferences, and availability
- **Advanced Filtering** - Search by skills, experience, reliability, location, and availability
- **Mobile-Optimized Design** - Responsive interface with touch-friendly navigation
- **Theme Support** - Light, dark, and system theme modes
- **GitHub Integration** - Verify GitHub profiles and showcase repositories
- **Social Links** - LinkedIn, GitHub, and portfolio integration
- **Avatar System** - Gender-based defaults with custom upload support
- **Text Formatting** - Smart formatting for better content readability
- **Performance Optimized** - Fast loading with efficient caching and real-time sync
