HackMates - Hackathon Team Formation Platform

HackMates is a comprehensive platform designed to connect developers, designers, and innovators for hackathons across India. It simplifies team formation, hackathon discovery, and collaboration with AI-powered features and smart matching algorithms.

FEATURES:

1. Hackathon Discovery & Management
   - Browse and search hackathons by skills, location, and mode
   - Filter by online/offline/hybrid events
   - Host and organize your own hackathons
   - Real-time hackathon status tracking

2. Smart Team Formation
   - Find teammates based on skills and interests
   - AI-powered team recommendations
   - Synergy score matching (compatibility algorithm)
   - Team size management (2-4 members)

3. Team Contract & Anti-Ghosting
   - Commitment system before hackathon starts
   - Team locks after all members commit
   - Reliability score penalties for leaving after commitment
   - Prevents last-minute dropouts

4. GitHub Proof of Work Verification
   - Verify coding activity from last 3 months
   - Activity badges: Inactive/Active Coder/Prolific Coder
   - Shows commit count, repositories, and last activity
   - Trust score impact based on activity level

5. Reliability & Trust System
   - Reliability badges: Newbie/Reliable/Finisher/Legend
   - Track hackathon completion rate
   - Team feedback and ratings after events
   - Public reputation visible on profiles

6. AI Assistant (Gemini-Powered)
   - Get hackathon recommendations
   - Ask questions about platform features
   - Receive personalized suggestions
   - Context-aware responses

7. Real-time Communication
   - Direct messaging between users
   - Team chat within hackathons
   - Announcement system for organizers
   - Unread message notifications

8. Comprehensive User Profiles
   - Skills, interests, and experience levels
   - Work style preferences (goal, time, commitment)
   - Social links (LinkedIn, GitHub, Portfolio)
   - Avatar upload with gender-based defaults
   - Location and availability settings

9. Team Feedback System
   - Rate teammates after hackathon completion
   - Skill-based feedback (Frontend, Backend, Design, etc.)
   - Anonymous or named reviews
   - Contribution tracking

10. Advanced Search & Filters
    - Search profiles by skills and interests
    - Filter hackathons by multiple criteria
    - Sort by relevance, date, or popularity
    - Location-based filtering

11. Notifications & Updates
    - Real-time notification bell
    - Hackathon announcements
    - Team invitations and updates
    - Message notifications

12. Responsive Design
    - Mobile-friendly interface
    - Dark/Light theme toggle
    - Smooth animations and transitions
    - Modern glassmorphism UI

13. Authentication & Security
    - Firebase authentication
    - Email/password login
    - Secure user data storage
    - Profile privacy controls
