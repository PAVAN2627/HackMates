1. SYSTEM OVERVIEW
================================================================================

HackMates is India's premier AI-powered hackathon discovery and team formation 
platform that revolutionizes how developers, designers, and innovators connect 
and collaborate. Built with cutting-edge technology, HackMates provides 
intelligent matching, trust-based team formation, and comprehensive hackathon 
management tools.

MISSION
-------
To democratize innovation by connecting passionate developers, designers, and 
creators across India's vibrant tech ecosystem through intelligent matching 
and trust-based collaboration.

VISION
------
To become the go-to platform where India's next breakthrough innovations are 
born through meaningful collaborations and hackathon experiences.

TECHNOLOGY STACK
----------------
Frontend:
  • React 18 with TypeScript
  • Vite for lightning-fast builds
  • Tailwind CSS for modern styling
  • Radix UI & shadcn/ui components

Backend & Services:
  • Firebase Firestore (NoSQL database)
  • Firebase Authentication
  • Firebase Storage
  • Google Gemini AI API

Key Libraries:
  • React Router for navigation
  • React Hook Form for forms
  • date-fns for date handling
  • Sonner for notifications
  • Lucide React for icons

✓ Detailed Breakdown

  - Visual compatibility indicators

4. TRUST & RELIABILITY SYSTEM
================================================================================

4.1 RELIABILITY BADGES
-----------------------
✓ 4-Tier Badge System
  - 🌱 Newbie: No hackathon history yet
  - ✓ Reliable: Completed 1+ hackathon with 60%+ score
  - ⭐ Finisher: Completed 3+ hackathons with 75%+ score
  - 👑 Legend: Completed 10+ hackathons with 85%+ score

✓ Trust Score Calculation (0-100)
  - 70% weight: Completion rate (completed vs ghosted)
  - 30% weight: Average rating from teammates
  - Transparent scoring algorithm
  - Real-time score updates

✓ Badge Display
  - Compact badge on profiles
  - Detailed badge view with statistics
  - Color-coded levels (Gray, Blue, Green, Gold)
  - Tooltip with quick info
  - Full breakdown available

4.2 TEAM FEEDBACK SYSTEM
-------------------------
✓ Post-Hackathon Feedback Collection
  - Triggered when hackathon closes
  - Rate only your small team members (not all participants)
  - Prevents rating fatigue in large hackathons
  - One-time feedback per teammate per hackathon

✓ Feedback Components
  - Contribution status (Did contribute vs Ghosted)
  - Star rating (1-5 stars) if contributed
  - Skills demonstrated (9 predefined skills)
  - Optional written comments
  - Anonymous feedback option

✓ Feedback Flow
  - Step-by-step wizard interface
  - Progress indicators
  - Previous/Next navigation
  - Bulk submission at the end
  - Duplicate prevention
  - Already-rated indicator

✓ Skills Tracking
  - Frontend, Backend, UI/UX
  - Database, DevOps
  - Problem Solving, Communication
  - Leadership, Debugging
  - Aggregated skill endorsements

4.3 TRUST INDICATORS
---------------------
✓ Profile Trust Signals
  - Reliability badge prominently displayed
  - Trust score with description
  - Hackathons completed count
  - Success rate percentage
  - Average rating from teammates
  - Special achievement badges

✓ Warning Flags
  - Ghost warning for <50% completion rate
  - Low trust score indicators
  - Multiple ghosting incidents

✓ Achievement Badges
  - 🏅 Veteran: 10+ hackathons completed
  - 👻 Never Ghosted: 100% completion with 5+ hackathons
  - ⭐ Highly Rated: 4.5+ average rating with 5+ reviews
  - ✨ Perfect Record: 3+ hackathons, zero ghosting
