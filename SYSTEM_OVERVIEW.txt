================================================================================
                        PROJECT DESCRIPTION
================================================================================

HackMates is India's premier hackathon discovery and team formation platform
that connects developers, designers, and innovators across the country. The
platform provides comprehensive tools for hackathon discovery, intelligent
team matching, real-time communication, and community trust building.

Mission: Democratize innovation by connecting passionate developers, designers,
and creators across India's vibrant tech ecosystem.

Vision: Become the go-to platform where India's next breakthrough innovations
are born through meaningful collaborations and hackathon experiences.

================================================================================
                        TECHNOLOGY STACK
================================================================================

FRONTEND FRAMEWORK:
- React 18.3.1 (Modern UI library with hooks and concurrent features)
- TypeScript 5.6.2 (Type-safe development)
- Vite 5.4.2 (Lightning-fast build tool and dev server)

UI & STYLING:
- Tailwind CSS 3.4.1 (Utility-first CSS framework)
- Radix UI (Accessible, unstyled UI primitives)
- shadcn/ui (Beautiful, customizable component library)
- Lucide React 0.469.0 (Icon library)
- Sonner (Toast notifications)

BACKEND & DATABASE:
- Firebase Firestore (NoSQL real-time database)
- Firebase Authentication (User authentication system)
- Firebase Storage (Cloud storage for images/files)
- Firebase Cloud Messaging (Push notifications)

STATE MANAGEMENT:
- React Context API (Auth, Theme management)
- Custom Hooks (Data fetching and business logic)
- Firebase Real-time Listeners (Live data sync)

AI & INTEGRATIONS:
- Google Gemini AI (AI-powered assistant)
- Google Apps Script (Email service)
- GitHub API (Profile verification)

ROUTING:
- React Router DOM 6.28.0 (Client-side routing)

DEPLOYMENT:
- Vercel (Production hosting)
- Firebase Hosting (Alternative option)

================================================================================
                        DATABASE SCHEMA
================================================================================

FIRESTORE COLLECTIONS:

1. users/
   - uid: string (document ID)
   - email: string
   - name: string
   - avatar: string | null
   - bio: string
   - skills: string[]
   - experience: string
   - location: string
   - linkedIn: string
   - github: string
   - portfolio: string
   - lookingForTeam: boolean
   - workStyle: {
       goal: 'win' | 'learn' | 'both'
       timePreference: 'morning' | 'afternoon' | 'evening' | 'night' | 'flexible'
       commitment: 'full-time' | 'part-time' | 'casual'
     }
   - reliability: {
       badge: 'newbie' | 'reliable' | 'finisher' | 'legend'
       trustScore: number (0-100)
       hackathonsCompleted: number
       hackathonsJoined: number
       averageRating: number
     }
   - createdAt: Timestamp

2. hackathons/
   - id: string (document ID)
   - title: string
   - description: string
   - imageUrl: string
   - startDate: Timestamp
   - endDate: Timestamp
   - location: string
   - mode: 'online' | 'offline' | 'hybrid'
   - requiredSkills: string[]
   - teamMembers: string[] (user IDs)
   - maxTeamSize: number
   - creatorId: string
   - status: 'open' | 'closed'
   - createdAt: Timestamp

3. teamChats/
   - id: string (document ID)
   - hackathonId: string
   - teamId: string
   - content: string
   - authorId: string
   - createdAt: Timestamp
   - edited: boolean
   - editedAt: Timestamp (optional)

4. directMessages/
   - id: string (document ID)
   - senderId: string
   - recipientId: string
   - content: string
   - read: boolean
   - createdAt: Timestamp
   - participants: string[] (array of both user IDs)

5. announcements/
   - id: string (document ID)
   - hackathonId: string
   - title: string
   - content: string
   - authorId: string
   - authorName: string
   - createdAt: Timestamp
   - readBy: string[] (user IDs who read it)

6. teamFeedback/
   - id: string (document ID)
   - hackathonId: string
   - reviewerId: string
   - reviewedUserId: string
   - rating: number (1-5)
   - comment: string
   - createdAt: Timestamp

FIRESTORE INDEXES REQUIRED:

1. teamChats:
   - hackathonId (Ascending) + teamId (Ascending) + createdAt (Ascending)

2. announcements:
   - hackathonId (Ascending) + createdAt (Descending)

3. directMessages:
   - participants (Array) + createdAt (Descending)

================================================================================
                        KEY ALGORITHMS
================================================================================

1. SYNERGY SCORE CALCULATION:
   - Goal Alignment: 40 points (same goal = 40, different = 20, both = 30)
   - Time Preference: 30 points (same = 30, flexible = 20, different = 10)
   - Commitment Level: 30 points (same = 30, adjacent = 20, different = 10)
   - Total: 0-100% compatibility score

2. TRUST SCORE CALCULATION:
   - Base Score: (hackathonsCompleted / hackathonsJoined) * 50
   - Rating Bonus: (averageRating / 5) * 50
   - Total: 0-100 trust score

3. RELIABILITY BADGE ASSIGNMENT:
   - Newbie: trustScore < 30 OR hackathonsCompleted < 2
   - Reliable: trustScore >= 30 AND hackathonsCompleted >= 2
   - Finisher: trustScore >= 60 AND hackathonsCompleted >= 5
   - Legend: trustScore >= 80 AND hackathonsCompleted >= 10

4. AI RECOMMENDATION ALGORITHM:
   - Analyzes user skills, experience, and work style
   - Matches with hackathon requirements
   - Considers team composition and skill gaps
   - Provides compatibility scores and reasoning

================================================================================
                        SECURITY & PERMISSIONS
================================================================================

FIREBASE SECURITY RULES:

Firestore:
- Users: Read all, write own profile only
- Hackathons: Read all, create if authenticated, update if creator/member
- Messages: Read/write only if sender or recipient
- Announcements: Read all, write if hackathon creator
- Team Feedback: Write if authenticated, read own feedback

Storage:
- User Avatars: Read all, write own avatar only
- Hackathon Images: Read all, write if authenticated

Authentication:
- Email/Password authentication
- Password reset functionality
- Session persistence
